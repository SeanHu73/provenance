# Style Guide: The Ledger (1970s New Journalism)

*"Editorial drama meets approachable warmth. High-contrast type and vivid accents stay legible in direct sunlight."*

**Persona:** Friendly Guide

## Typography
- **Display (52px):** DM Serif Display
- **Heading 1 (36px):** DM Serif Display
- **Heading 2 (24px):** DM Serif Display
- **Lead (18px):** Outfit
- **Body (15px):** Outfit
- **Caption (12px):** Outfit
- **Overline (11px):** Outfit, uppercase, tracking wide

**Font pairing:** DM Serif Display (display) + Outfit (body)

## Components
- **Primary button:** Solid #8B2538, white text, rounded
- **Secondary button:** Outline #8B2538, transparent bg
- **Tertiary button:** Outline dark, transparent bg
- **Badges:** Solid primary for category, outline for metadata
- **Cards:** White bg, subtle border, rounded-lg
- **Inputs:** Light border, rounded

## Tokens
- **Spacing:** 4, 8, 12, 16, 24, 32, 48, 64, 96
- **Border radius:** none, sm (2px), md (12px), lg (16px)
- **Elevation:** sm, md, lg (increasing shadow)
